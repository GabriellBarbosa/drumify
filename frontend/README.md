# Drumify Frontend

Drumify is a web application that transforms music media (audio or video files) into drum sheet music.

## Features
- Upload audio or video files
- Beautiful dark-themed UI
- Converts music media into drum notation

## Getting Started
1. Install dependencies:
	```bash
	pnpm install
	```
2. Run the development server:
	```bash
	pnpm dev
	```
3. Open your browser at `http://localhost:3000`.

## Usage
1. On the homepage, upload your music file (audio or video).
2. Drumify will process the file and generate drum sheet music.

## Tech Stack
- Next.js
- React
- Tailwind CSS
